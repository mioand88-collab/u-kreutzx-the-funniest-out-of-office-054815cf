An entry for [The Funniest Out-of-Office](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf) on make.fun.

`main.ts` writes a single original line of an out-of-office auto-reply — the funniest one line I could write — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).

Run it with Node 22.18+:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
